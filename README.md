# ЦЕХ-84

Лендинг столярной мастерской с галереей работ и формой заявки.

Для локального запуска нужен Node.js 24. Выполните `node serve.mjs` и откройте http://127.0.0.1:4184 в браузере. Установка пакетов не требуется.

Заявки сохраняются в локальной базе SQLite. Команда `node serve.mjs --requests` выводит список заявок владельцу сервера.
